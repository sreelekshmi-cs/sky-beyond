# Sky & Beyond 

A responsive image gallery built using React, Vite, and Tailwind CSS.

## Features
- Dynamic image gallery
- Search photographs
- Filter images by category
- Add and remove favorites
- View images in a popup
- Download images
- Responsive design for mobile and desktop

## Technologies Used
- React.js
- JavaScript
- Tailwind CSS
- Vite
- Font Awesome

## Run Locally

1. Clone the repository.
2. Open the project folder.
3. Install dependencies using `npm install`.
4. Start the project using `npm run dev`.

## About

Sky & Beyond is a celestial photography gallery showcasing the moon, clouds, stars, sunsets, auroras, and galaxies.
